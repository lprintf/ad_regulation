# 开发注意事项

## 常见警告与错误

- DeprecationWarning: datetime.datetime.utcnow() is deprecated and scheduled for removal in a future version. Use timezone-aware objects to represent datetimes in UTC: datetime.datetime.now(datetime.UTC).
- beanie 2.0 不再使用 motor 作为数据库驱动，且接口有较大改动，建议使用时查看context7查看最佳实践.

## 技术选型

注：可以使用 context7 MCP 查找相关技术文档与最佳实践。

- python 3.12
- 使用 beanie>=2.0 作为Mongodb DOM，不使用motor，使用 pymongo 的 AsyncMongoClient 作为异步数据库驱动。
- 使用 SQLModel 作为ORM，使用 SQLite(开发环境)/PostgreSQL 作为数据库。
- 使用 antd 作为前端组件库。
